# 📚 Library Management System

This project is a **Library Management System** designed to efficiently manage a library’s operations. It helps maintain records of books, customers, employees, branches, and book issuance/returns.
The system is built using **SQL**, ensuring accurate storage, easy retrieval, and smooth handling of all library-related data.

---

## 🗄️ Database Setup

Create a new database named:

```
Library
```

All tables, relations, and queries are stored inside this database.

---

## 🚀 Features

### 📘 **Book Management**

- Add, update, and remove books.
- Track title, category, rental price, availability, author, and publisher.

### 👤 **Customer Management**

- Store customer details such as name, address, registration date.
- Track issuance history and current book status.

### 👨‍💼 **Employee Management**

- Maintain employee records including name, position, salary.
- Manage branch assignments.

### 🔄 **Book Issuance & Return**

- Record issuing of books to customers.
- Track due dates, return status, and ensure timely returns.

### 🏢 **Branch Management**

- Maintain details of library branches.
- Include branch numbers, addresses, managers, and contact info.

---

## 📊 SQL Queries & Analysis

The project includes SQL queries for insights and analysis. These include:

1. Retrieve the book title, category, and rental price of all available books.
2. List employee names and salaries in descending order of salary.
3. Retrieve book titles and the customers who issued them.
4. Display the total count of books in each category.
5. Retrieve employee names and positions for employees earning above ₹50,000.
6. List customers who registered before **2022-01-01** and haven’t issued any books.
7. Display branch numbers and the total employee count in each branch.
8. Retrieve customers who issued books in **June 2023**.
9. Retrieve all book titles from the category **"History"**.
10. Retrieve branch numbers with employee count greater than 5.
